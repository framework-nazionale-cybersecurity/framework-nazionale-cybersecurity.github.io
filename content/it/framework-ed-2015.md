Questa pagina consente di scaricare i documenti le tabelle del Framework Nazionale per la Cyber Security v1.0 in formato excel. I fogli excel possono essere utilizzati per creare contestualizzazioni del Framework. Le contestualizzazioni create possono essere inviate [staff@cybersecurityframework.it&nbsp;](mailto:staff@cybersecurityframework.it?subject=Richiesta%20materiale%20di%20supporto) e su richiesta potranno essere pubblicate su questo sito. 

Qualunque altro materiale di supporto può essere richiesto all'indirizzo [staff@cybersecurityframework.it&nbsp;](mailto:staff@cybersecurityframework.it?subject=Richiesta%20materiale%20di%20supporto). Tale indirizzo può anche essere utilizzato per comunicazioni o per segnalazioni di errori sui documenti. Si ricorda inoltre che il Framework subirà aggiornamenti, quindi eventuali proposte di emendamento o di collaborazione saranno opportunamente valutate. 

[**Framework Nazionale per la Cyber Security**](/sites/default/files/CSR2015_web.pdf)

Il Framework Core in formato excel corrisponde al Framework Core del NIST Framework for Improving Critical Infrastructure Cybersecurity v1.0 tradotto in italiano con l'aggiunta di alcune informatioin reference relative al panorama normativo italiano.
