This page allows to download the excel sheet of the National Cyber Security Framework Core. The excel sheet can be used to create Framework's Contextualizations. The create contextualizations can be sent to [staff@cybersecurityframework.it](mailto:staff@cybersecurityframework.it?subject=contextualization%20submitted) to be evaluated and published in this website upon request.

Other support material can be requested using the e-mail address [staff@cybersecurityframework.it](mailto:staff@cybersecurityframework.it?subject=Support%20material%20request) The same e-mail can be used to communicate errors on the documents. The Framework will be updated, any proposed amendament or any collaboration proposal will be accurately considered. 

**Framework Core in Excel** (english version): [Framework Core ENG](/sites/default/files/core%20ing.xlsx)

**Framework Core** with priority levels: [Framework Core with priority levels](/sites/default/files/core%20PMI%20ing.xlsx)
